# AI Music Downloader

Repository pemulihan sementara setelah akun GitHub lama tidak dapat diakses.

## Sumber pemulihan

Arsip portable yang berhasil diselamatkan: `AI-Music-Downloader-Portable(3).zip`.

Arsip berisi build Windows portable, termasuk `AI Music Downloader.exe`, dependensi Python/PySide6, spotDL, FFmpeg/FFprobe, Deno, konfigurasi contoh, acceptance test Windows 11, database antrean, metadata rilis, dan file lisensi.
